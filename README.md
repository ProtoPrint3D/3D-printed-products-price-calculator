# 3D-printed-products-price-calculator
تطبيق مكتبي مفتوح المصدر يساعد أصحاب مشاريع الطباعة ثلاثية الأبعاد على حساب تكاليف المنتجات، وتحديد أسعار مربحة، وإدارة مختلف متغيرات التسعير.
An open-source desktop application that helps 3D-printing businesses calculate product costs, set profitable prices, and manage pricing variables.
Une application de bureau open source permettant aux professionnels de l’impression 3D de calculer les coûts de leurs produits, de fixer des prix rentables et de gérer leurs paramètres de tarification.
